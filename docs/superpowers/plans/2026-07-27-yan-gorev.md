# Yan Görev Demo Sitesi — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kurgusal oyun dergisi + forum demosu "Yan Görev"i saf statik HTML/CSS/JS ile inşa edip GitHub + Vercel entegrasyonuyla otomatik deploy akışına bağlamak.

**Architecture:** 3 şablon sayfa (`index.html`, `oyun.html`, `konu.html`) `js/data.js`'teki kurgu veriden `js/app.js` ile client-side render edilir. `?id=` parametresi tek şablondan çok sayfa üretir. Yorum/beğeni etkileşimi localStorage'da sahtelenir. Build adımı yok; Vercel dosyaları olduğu gibi servis eder.

**Tech Stack:** HTML5, CSS (custom properties), vanilla JS (ES2020), Google Fonts (maks. 2 aile), git + gh CLI, Vercel GitHub entegrasyonu.

## Global Constraints

- Tüm içerik KURGU: gerçek oyun/stüdyo/marka adı kesinlikle yok (spec §5).
- İçerik dili Türkçe; her sayfada `<html lang="tr">`.
- Framework, build adımı, harici JS kütüphanesi yok (spec §3).
- Tek vurgu rengi; şablonvari "AI görünümü" yasak (spec §7) — tasarım kararları frontend-design skill'i ile verilir.
- Kullanıcı verisi DOM'a `textContent` ile basılır (innerHTML'e ham metin yok).
- Her görev kendi commit'iyle biter; Task 6'dan sonra her commit push'lanır (deploy'u tetikler).
- 🎓 işaretli adımlar yeni ekip arkadaşının KULLANICI KATKISI'dır: iskelet hazırlanır, kararı/kodu o yazar (spec §8). Bu adımlar subagent'a devredilmez.
- Doğrulama komutu: `python3 -m http.server 7777` + tarayıcı/headless ekran görüntüsü (statik sitede test framework'ü yok; doğrulama görseldir).

### Task 4: Render motoru — js/app.js + üç sayfanın main içerikleri

**Files:**
- Modify: `js/app.js`, `index.html`, `oyun.html`, `konu.html`

**Interfaces:**
- Consumes: `OYUNLAR`, `KONULAR` (Task 2); CSS sınıfları (Task 3).
- Produces: `paramId(varsayilan)`, `el(tag, sinif, metin)`, `sayfayiKur()` + sayfa render fonksiyonları; `konu.html`'de `<form id="yorum-form">` ve `yorumKaydet(konuId, rumuz, metin)` çağrısı (gövdesi Task 5'te).

- [ ] **Step 1: Yardımcılar ve yönlendirici**

```js
function paramId(varsayilan) {
  return new URLSearchParams(location.search).get("id") || varsayilan;
}
function el(tag, sinif, metin) {
  const e = document.createElement(tag);
  if (sinif) e.className = sinif;
  if (metin !== undefined) e.textContent = metin; // XSS'e kapalı: her zaman textContent
  return e;
}
function sayfayiKur() {
  const sayfa = location.pathname.split("/").pop() || "index.html";
  if (sayfa === "oyun.html") oyunSayfasi();
  else if (sayfa === "konu.html") konuSayfasi();
  else anaSayfa();
}
document.addEventListener("DOMContentLoaded", sayfayiKur);
```

- [ ] **Step 2: `anaSayfa()`** — `main#icerik` içine: manşet (`manset:true` oyun; başlık `oyun.html?id=` bağlantılı, puan rozeti, özet), `#incelemeler` kart grid'i (kalan 5 oyun), `#forum` liste (6 konu: başlık `konu.html?id=` bağlantılı, açan, yorum sayısı).

- [ ] **Step 3: `oyunSayfasi()`** — `OYUNLAR.find(o=>o.id===paramId(OYUNLAR[0].id)) || OYUNLAR[0]`; başlık, künye satırı, puan rozeti, inceleme paragrafları, artı/eksi kutusu, `konu.html?id=«konuId»` bağlantısı. `document.title` oyun adına güncellenir.

- [ ] **Step 4: `konuSayfasi()`** — konu başlığı + açılış mesajı + kurgu yorumlar + kullanıcı yorumları + form. Bu görevde `yorumKaydet` ve `kullaniciYorumlari` BOŞ STUB olarak eklenir (`yorumKaydet(){}` hiçbir şey yapmaz, `kullaniciYorumlari(){ return []; }`); gövdeleri Task 5'te 🎓 doldurulur. Form:

```html
<form id="yorum-form">
  <input name="rumuz" placeholder="Rumuzun" required maxlength="24">
  <textarea name="metin" placeholder="Yorumunu yaz…" required maxlength="1000"></textarea>
  <button type="submit">Gönder</button>
</form>
```

Form submit → `yorumKaydet(konu.id, rumuz, metin)` → listeyi yeniden çizer. Beğeni: her yorumda buton; `localStorage["yg-begeni-«konuId»-«index»"]` 0/1; tıklama sayacı artırır/geri alır.

- [ ] **Step 5: Doğrula** — üç sayfa + `?id=` varyasyonları ve geçersiz `?id=abc` (ilk kayda düşmeli) gezilir; ekran görüntüleriyle bakılır.
